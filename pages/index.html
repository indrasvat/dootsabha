for the agent calling it

A contract, not a chat.

--json

Exactly one document on stdout. Logs stay on stderr.

schema_version: 1

On every JSON document. Fields are added, never renamed.

exit 0 2 3 4 5 6

One code per caller action. Branch on it; never parse prose.

--progress-file

NDJSON to tail while it runs. The last line holds the exit code.

status --json

Which agents are installed and answering, before you plan.

--timeout

A budget per call, a ceiling per run. Both exit 4 and say which fired.

SIGTERM

Every agent stops first. The run still records how it ended.
